# Gram Connect – Rural Telangana Government Scheme Assistant

## Purpose

This document defines the responsibilities of team members (agents) and the workflow for project development.

---

## Project Goal

Develop an AI-powered platform that helps rural citizens of Telangana discover government schemes, check eligibility, understand required documents, and receive assistance through an intelligent chatbot.

## Development Workflow

1. Each member works on an assigned branch.
2. Code is committed regularly.
3. Merge Requests must be created before merging into main.
4. Project Lead reviews and approves changes.
5. Only reviewed code is merged into the main branch.

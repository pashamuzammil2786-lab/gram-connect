# User Manual

## Project Name

**Gram Connect – Rural Telangana Government Scheme Assistant**

---

## 1. Introduction

Gram Connect is an AI-powered web application designed to help rural citizens of Telangana easily access information about government schemes, check eligibility, understand required documents, and receive assistance through a user-friendly interface.

---

## 2. Purpose

The purpose of Gram Connect is to:

* Increase awareness of government welfare schemes.
* Help citizens identify schemes they are eligible for.
* Provide document and application guidance.
* Offer support through an AI-based assistant.
* Improve access to government services in rural areas.

---

## 3. System Requirements

### Hardware Requirements

* Computer or Laptop
* Internet Connection

### Software Requirements

* Modern Web Browser (Chrome, Edge, Firefox)
* Internet Access

---

## 4. User Roles

### Citizen/User

Can:

* Search government schemes
* Check eligibility
* View required documents
* Interact with the AI assistant

### Administrator

Can:

* Update scheme information
* Manage application data
* Monitor system usage

---

## 5. Features

### 5.1 Scheme Search

Users can search for schemes based on categories such as:

* Farmers
* Students
* Women
* Senior Citizens
* Unemployed Youth

### 5.2 Eligibility Checker

Users enter:

* Age
* Occupation
* Income Details

The system displays eligible schemes.

### 5.3 AI Assistant

Users can ask questions in simple language and receive guidance regarding:

* Government schemes
* Eligibility criteria
* Required documents
* Application procedures

### 5.4 Document Guidance

The system provides information about:

* Aadhaar Card
* Income Certificate
* Caste Certificate
* Ration Card
* Other required documents

---

## 6. How to Use the Application

### Step 1

Open the Gram Connect application.

### Step 2

Navigate to the Home Page.

### Step 3

Select a service:

* Search Schemes
* Eligibility Checker
* AI Assistant

### Step 4

Enter the required details.

### Step 5

View the results and recommendations.
